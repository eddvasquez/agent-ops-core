# Changelog

Todos los cambios relevantes de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/). Reglas del Protocolo 7 de `AGENTS.md`:

- Cada cambio entregable añade una línea en `[Unreleased]` en el mismo commit, bajo `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed` o `Security`.
- Publicar una versión mueve `[Unreleased]` a `## [X.Y.Z] - AAAA-MM-DD`, actualiza la versión declarada y crea el tag anotado `vX.Y.Z`.
- Despliegues fuera de Git (WordPress, GTM, Ads…): registrar versión, destino, fecha y verificación.
- Conservar como máximo 10 versiones aquí; las anteriores pasan a `changelogs/archive/project.md`.
