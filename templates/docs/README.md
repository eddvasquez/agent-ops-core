# Documentación y Entregables del Proyecto (`docs/`)

Esta carpeta es el repositorio central para toda la documentación formal, requerimientos y entregables terminados del proyecto.

---

## Qué se Guarda en Esta Carpeta (`docs/`)
* **Briefs y Requerimientos del Negocio:** Documentos de objetivos, perfiles de avatar/cliente, directrices de marca y alcances del proyecto.
* **Informes de Investigación y Análisis:** Estudios de mercado, análisis de competencia, encuestas de experiencia de usuario (UX) y reportes de auditoría.
* **Manuales Operativos y Procedimientos (SOPs):** Guías paso a paso, manuales de usuario y especificaciones técnicas.
* **Entregables Formales:** Documentos finales listos para revisión de clientes, gerencia o partes interesadas.

---

## Qué NO se Guarda en Esta Carpeta
1. **Memoria Operativa de la IA:** La memoria histórica, bitácora de tareas, lecciones aprendidas y contexto activo pertenecen exclusivamente a la carpeta `📁 .context/` en la raíz.
2. **Archivos Duplicados Informales:** Prohibido guardar archivos con sufijos de versionado (`_v2`, `_final`, `_copia`). Toda evolución de un documento se versiona de forma limpia y transparente mediante Git.
3. **Archivos Temporales o Dependencias Masivas:** Las descargas pesadas o archivos efímeros no deben residir en esta carpeta.
